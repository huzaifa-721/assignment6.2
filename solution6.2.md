 I built three different pricing cards named Basic, Standard, and Premium, each containing a title, description, price, and a button. To keep the designs distinct, I applied different background colors and borders: Basic has a light blue background with a solid blue border, Standard has a gradient green background with a dashed green border, and Premium has a dark background with a double golden border and box shadow to make it stand out. All cards have rounded corners using border-radius property, with Basic having 16px, Standard having 24px for a softer look, and Premium having different radius values for each corner (12px 36px) for a unique style. I also set fixed width of 300px, height of 350px, and max-width of 90% to make them responsive on mobile devices. For the display property demonstration, I showed that display block, which is default for div, takes the full width and always starts on a new line, so two block elements stack vertically. Display inline, which is default for span, takes only the content width and stays on the same line, but width and height properties do not work on it. Display inline-block combines both advantages, it stays inline like inline elements but allows width and height to be set like block elements, making it perfect for creating card layouts, navigation menus, and buttons that need to sit side by side with fixed dimensions.
